# Licensing

BSD 3-Clause is the standard license for new WLAN Pi projects. A few older
repositories are still MIT (`wlanpi-chat-bot`, `wlanpi-kernel`,
`wlanpi-misc-packages`; `wlanpi-chat-bot` is archived). Treat BSD-3-Clause as
the target when touching licensing in a repo. See
[Repository Reference](../REPOS.md) for the current license of each repo.
